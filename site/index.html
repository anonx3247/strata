What Strata changes for agents

Contracts

One ledger, written twice. A transfer must never make or lose money.

In Rust, that rule is a comment, and three tests check it on the accounts someone picked. They pass. In Strata, the rule is a law on the trait, next to a refinement type (Cents, never negative) and a contract on transfer. verify checks the implementation against all of them, and finds the transfer the tests never tried: from account 100 to itself, which adds 9 cents to it.

FAQ

How is this different from Dafny, F* or Liquid Haskell?

The contracts are the same idea: refinement types, requires and ensures, checked by an SMT solver. Strata differs around them. Where the solver can't decide, a fuzzer runs the function against the contract, and the verdict says which of the two it came from. Code is stored as a syntax tree, so unfinished code with holes still checks, and every edit is checked before it is stored. And it is built to be used by agents, through a command line.

And from Unison?

Unison also stores code as definitions identified by a hash of their content. Strata adds contracts and verification to that, and keeps text as a view: agents and people read and write ordinary text, which strata edit parses back into the tree.

What exactly does "proven" mean?

The solver (Z3, or cvc5) showed that a check holds for every input, under Strata's encoding of the program. What you trust is the solver, that encoding, the compiler and the C runtime. Code the solver can't reason about, such as a disk behind a capability or an extern c function, is assumed, and reported as assumed. Termination is proven, or reported as unproven. How does an agent learn to use it?

strata skill install writes a short skill into the folders where coding agents look for them. It says that .strata files are binary, that code is read and changed through strata, and lists the commands. Learn Strata in Y minutes is the whole language as one valid file, written to be given to an agent.

Which platforms does it run on?

macOS on Apple silicon. There is no Linux build yet. Building from source needs an existing strata, because the compiler is written in Strata.

Can I use it for real work?

Not yet. This is a pre-alpha prototype: expect breaking changes, rough edges and bugs. A rebuild is under way. How it was built →
