What Strata changes for agents

Contracts

Proven for every input, instead of tested on a few.

Contracts instead of tests

One ensures replaces the tests. The solver proves it for every input.

In the tour →

Refinement types

Types carry constraints, functions say what they need and give. Every call is checked.

In the tour →

Trait laws

A trait states how its methods combine. Every implementation is proven against it.

In the tour →

Editing the syntax tree

Code is stored as its syntax tree, not as text files.

Structural diffs

A diff lists what happened to definitions, not the lines that moved.

In the tour →

Views

An agent reads the part it needs, at the detail it needs.

In the tour →

Typed holes

Unfinished code still type-checks. An edit that doesn't check is refused.
