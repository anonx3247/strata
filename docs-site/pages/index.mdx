Strata is an experimental language for working with agents. Types carry constraints, an SMT solver proves contracts (or a fuzzer tests the ones it can't), unfinished code is a typed hole, and side effects are capabilities passed as parameters.

Install it (macOS on Apple silicon; [other ways](/docs/tools/#installing)):

```sh
curl -fsSL https://strata-lang.dev/install.sh | sh
```
